# Photos for the site

Drop your photos into **this folder** (`assets/img/`) using the **exact file names**
below. The website loads them automatically — no code changes needed. Until a photo
exists, the site shows a clean designed placeholder in its place, so nothing ever looks broken.

| File name        | Where it shows            | Suggested photo                                                        |
| ---------------- | ------------------------- | ---------------------------------------------------------------------- |
| `portrait.jpg`   | About section (portrait)  | A clear portrait of you (tall / vertical works best)                   |
| `president.jpg`  | Gallery (large)           | Receiving the Bal Puraskar from President Droupadi Murmu               |
| `pm-modi.jpg`    | Gallery                   | With Prime Minister Narendra Modi                                       |
| `academy.jpg`    | Gallery                   | Training officers at the Sher-i-Kashmir Police Academy                  |
| `students.jpg`   | Gallery                   | A cyber-safety workshop with students                                  |
| `summit.jpg`     | Gallery (large)           | At the FutureCrime Summit / on stage                                    |

## Tips
- **Format:** `.jpg` (or rename a `.png`/`.jpeg` to end in `.jpg`).
- **Size:** aim for roughly 1200–1600px on the long edge and keep each file under ~500 KB
  so the page stays fast. You can compress at https://squoosh.app.
- **Names are case-sensitive** on GitHub Pages — use lowercase exactly as above.
- Want a different photo somewhere? Open `index.html`, search for the file name
  (e.g. `students.jpg`) and change it — the `alt` text and caption sit right next to it.

## A note on rights
Please only upload photos you own or are authorised to use. Award-ceremony photos are
usually released by the **PIB / Government of India press office** — those are generally
fine to use. Avoid re-uploading copyrighted press photographs without permission.
